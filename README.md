# Historical Interactive Video Game

## Overview

Historical Interactive Video Game is an educational project developed to promote the understanding of Colombian history through interactive and immersive experiences.

Inspired by the National Museum of Colombia, the game recreates representative historical events and environments, allowing players to learn about the country's past through exploration, interaction and gameplay mechanics.

The project was developed collaboratively by a multidisciplinary team using Unity and C#.

---

## Objectives

* Promote historical learning through interactive experiences.
* Increase engagement with Colombian history using game-based learning.
* Recreate representative historical scenarios in a virtual environment.
* Provide an educational alternative to traditional learning methods.

---

## Game Concept

Players explore historical environments inspired by important events and locations from Colombian history.

Throughout the experience, players interact with objects, characters and information points that provide historical context while completing objectives within the game world.

The project was designed as an educational tool that combines entertainment and learning.
